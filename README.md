# Awesome Link Building & Backlink Hygiene

Курируемый каталог лучших методологий, инструментов скоринга доноров и протоколов аудита ссылочного профиля для защиты сайтов от санкций поисковых систем (Яндекс Минусинск, Google SpamBrain).

Разработано и поддерживается экспертами [Бюро ссылочной гигиены](https://links-hygiene.ru/).

---

## Стандарты белого линкбилдинга

* **Двухконтурный отбор доноров:** 27 признаков алгоритмического скоринга + 40 параметров экспертной ручной проверки.
* **Принцип чистого профиля:** полный отказ от PBN-сеток, арендных биржевых сателлитов и спамных анкоров.
* **Еженедельный аудит (52 раза в год):** постоянный мониторинг сохранности купленных ссылок, статус-кодов страниц и отсутствия директив nofollow/noindex.
* **Работа только с живыми сайтами:** категорический отказ от линкбилдинга для доменов с нулевым органическим трафиком.
